# Learn Machine Learning with Colab

A Google Colab notebook that walks through the basics of machine learning, step by step.

[![Open In Colab](https://github.com/YadielCruz/IRML-CER3D_Dataset/blob/main/Module_1_Loading_IR_Spectra_for_Classification_Models.ipynb)

## What's inside

- Intro to ML concepts
- Working with data
- Training a simple model
- Evaluating results

## How to use

1. Click the **Open in Colab** badge above.
2. The notebook opens in your browser with a free hosted runtime — no installs needed.
3. Run the cells in order, top to bottom.
4. Follow along with the explanations and try the exercises.
5. To save your changes, go to **File > Save a copy in Drive**.
6. To exit, just close the tab.

### Running locally instead (optional)

1. Clone or download the repo.
2. In a terminal, create a virtual environment and install Jupyter:
   ```
   python -m venv venv
   venv\Scripts\activate      # Windows
   source venv/bin/activate   # macOS/Linux
   pip install notebook
   ```
3. Check the install: `jupyter --version`.
4. Launch it: `jupyter notebook`. It opens `http://localhost:8888/tree` in your browser (copy/paste the URL shown in the terminal if it doesn't open automatically).
5. Open `notebook.ipynb` and follow along.
6. To stop the server, press `Ctrl+C` in the terminal (confirm with `y`), or run `jupyter notebook stop`.

## Requirements

None for Colab. Local use requires Python and pip.
