# Learn Machine Learning with Colab

A Google Colab notebook that walks through the basics of machine learning, step by step.

## What's inside

- Intro to ML concepts
- Working with data
- Training a simple model
- Evaluating results

## How to use

1. Open `notebook.ipynb` in [Google Colab](https://colab.research.google.com/).
2. Run the cells in order, top to bottom.
3. Follow along with the explanations and try the exercises.

## Requirements

None — everything runs in Colab, no local setup needed.
